# 天猛星 Gmr 赛题控制台

当前Gmr是天猛星单一发布目标。顶层菜单分为`TASK`与`OTHER`；`TASK`保留原
Task2循迹A-A和H7 BMI滚球调试，并追加Task3视觉滚球、Task4循迹+滚球和Task5
循迹+滚球。原姿态、编码器、底盘、红外和步进测试保留在`OTHER`，同时新增BMI Y
前馈测试和`Stop Count Flash`参数页。旧地猛星、双车蓝牙和完整串口PID实现不进入
当前Gmr链接结果。

## 当前外设

| 外设 | 资源 | 当前用途 |
| --- | --- | --- |
| 左右编码电机 | TIMA0 PWM + 4路编码GPIO | Task2/4~7驱动，Task1/3/8强制停车 |
| 八路数字红外 | PA15/16/17/24/25/26/27、PB9 | Task2/6/7八路加权差速，高电平表示黑线 |
| 五个按键 | PB0/1/11/10/21 | K1/K2/K3/K4/K5，低电平按下 |
| H7通信 | UART2，PB15 TX | 单向发送LCD文本、前进加速度和H7控制请求；PB16不用连接 |
| 外部M0姿态 | UART3，PB2 TX / PB3 RX | 100 Hz连续yaw和yaw角速度 |
| 本地OLED | I2C0，PA0 SDA / PA1 SCL | 显示姿态数据和链路统计 |

UART0、UART1、蓝牙、云台STEP和IMU660RX在当前Gmr默认构建中不初始化。IR8占用
原IMU660RX SCK的PB9，两个模块不能同时启用。

## 当前任务

`Attitude`任务是被动监视页，显示：

- 连续yaw，单位0.01度转换为两位小数；
- yaw角速度，单位0.01度每秒转换为两位小数；
- M0发送序号、有效帧数和坏帧数。

任务进入和退出都会调用`EncoderMotor_Stop()`，不会根据姿态数据驱动电机。

`Task2 A-A`进入时清零左右累计编码器，随后持续使用八路红外加权差速循迹，
不请求H7按陀螺仪执行转向。基础速度从12 count/20ms起步，在2秒内线性升到
50 count/20ms。默认右轮count严格大于45000并且左轮count严格大于35200时，
立即停车并进入`Finished`；两个阈值必须同时满足。也可提前按K3停止任务。
Task2启动时同时开始计时，离开运行态时冻结；运行页和自动完成
页显示`MM:SS`；H7使用32像素原生字体，本地OLED使用24像素原生字体。其他没有
明确自动结束条件的测试任务不计时。

`Encoder`任务进入时会清零左右累计编码器count，随后持续显示左右带符号累计
count，供手推轮子检查正交编码器方向和计数。任务全程保持电机停车。

`Drive Adjustable`任务使用编码器速度闭环。主菜单按K2后先设置左轮，再设置右轮；
K1加1、K4减1、K2进入下一页或启动、K3返回。范围为0~100 count/20ms，默认
左15、右27。OLED运行页显示左右目标、实际反馈和raw PWM；任务持续运行到按K3
停止。首次运行必须架空车轮并准备物理断电。

`Direction +20`用于核对正方向。进入页面先停车；K1在`PWM +20%`与闭环
`+20 count/20ms`之间切换并停车，K2启动或停止当前模式。20%对应`+240 raw PWM`。
OLED显示左右Actual与raw PWM，正PWM时两侧实际编码都应为正。

`IR Differential`每20 ms读取IR1~IR8，按`14,10,6,2,-2,-6,-10,-14`
求激活通道平均位置。基础目标为左右50 count/20ms，位置误差乘2后形成差速并限制
在10~60；线在左侧时左轮减速、右轮加速，线在右侧时相反。丢线后沿用最后一次
有效红外状态对应的左右目标2000 ms，超时仍未重新检测到黑线才停车。
OLED显示八位IR mask以及左右Target、Actual和raw PWM。bit7～bit0依次对应
IR1～IR8，黑线为1、白底为0。

`Line Follow`与`Task2 A-A`使用同一套连续八路红外控制：左右基础目标均为50
count/20ms，红外位置误差直接形成左右轮差速。它不包含编码器分段、H7陀螺仪
转向、旧直角检测、强转或出弯状态；丢线仍保持最后目标2000 ms后停车。

`H7 BMI Ball`是H7滚球试验的M0菜单入口。Mission8本身保持两路底盘电机停车，
启动时只向H7发送一次`@BALL=BMI`请求；按K3、切换任务或进入错误状态时只发送
一次`@BALL=STOP`。发送失败时5 ms通信任务会重试，成功发送后不再周期发送。
BMI088、USART10视觉距离/球速和滚球步进控制均由H7独立持有，不经过M0，也不依赖
M0心跳保活。M0仅提供共享菜单和可选启停请求，不等待或解析H7确认。Mission8
开始后M0停止向H7发送LCD页面，滚球状态由H7本地刷新；返回M0主菜单时才恢复共享
菜单输出。

Task3/4/5分别使用内部Mission10/11/12。Task3保持底盘停车，只向H7发送
`@BALL=TASK3`；Task4/5一边运行八路红外循迹，一边分别发送`@BALL=TASK4`和
`@BALL=TASK5`。三套滚球参数位于H7的独立配置头文件，Task4/5循迹也不复用
TASK子菜单第1项的宏，三套循迹参数统一放在
`config/gmr_task_line_follow_config.h`并使用不同前缀。Task4/5启动时分别清零编码器；
共同基础速度以10 (count/20ms)/s从0增加到30。左右剩余里程都小于2250 count后
进入减速，并以10 (count/20ms)/s把共同基础速度降到0。弯道中的左右灰度差速先正常
计算，再乘相同的斜坡比例，因此减速时保持当时的左右速度比例。降到0后进入
`Finished`并停止底盘，但不发送`@BALL=STOP`，H7继续视觉平衡球；之后人工退出、
停止或切换任务时才停止H7滚球。

`OTHER -> Stop Count Flash`按Task1左、Task1右、Task4左、Task4右、Task5左、
Task5右的顺序编辑六个独立停车count。K1加100、K4减100、K2切换到下一项；在
Task5右侧按K2才会擦写Flash并进行CRC与写后校验，K3随时取消且不改运行值。允许
范围为1000～200000 count。Flash没有有效记录时使用配置宏默认值；有效记录位于
主Flash末尾`0x0001FC00`开始的1 KB保留扇区，重新烧写程序时应避免额外执行整片
Flash擦除，否则参数会恢复为宏默认值。

`BMI Y FF Test`位于`OTHER`，使用Mission13发送`@BALL=IMUY`。H7将重力去除后的
车体Y向线性加速度转换成步进位置前馈并叠加到视觉闭环；其轴向、符号、滤波、
死区、增益和限幅均由H7的`imu_y_feedforward_config.h`宏控制。

除`Stop Count Flash`编辑页外，本地按键均为短按：K1下一项、K4上一项、K2确认/
启动、K3退出/停止；K5事件已接入驱动，当前菜单暂未分配动作。

## H7协议

链路固定为115200、8-N-1，M0 PB15 TX接H7 PE7 RX，双方共地。Gmr不初始化UART2
RX、不启用UART2 RX中断，PB16无需连接。

M0到H7使用同一套换行结尾的文本协议：

```text
@CLEAR\n
@L0=GMR Tianmeng\n
@L1=> Attitude\n
@T=00:12\n
@A=1900\n
@BALL=BMI\n
@BALL=TASK3\n
@BALL=TASK4\n
@BALL=TASK5\n
@BALL=IMUY\n
@BALL=STOP\n
```

`@T=MM:SS`用于TASK子菜单五个任务的统一计时。TASK第1项在H7使用32像素原生
ASCII字库全屏显示；BMI滚球调试以及Task3/4/5在H7本机调参页标题栏显示，更新
计时不会退出调参页。后续收到`@CLEAR`或任意`@L0`至`@L9`命令时，H7退出计时
或调参页面并恢复普通文本显示。

`@A`每20 ms发送一次有符号十进制数，单位为
`0.01 (encoder count/20ms)/s`。它只表示左右轮共同前进基准速度的变化，不包含
八路红外循迹产生的左右差速。当前Task2在2秒起步斜坡内发送`@A=1900`；Task4/5
加速时发送`@A=1000`、减速时发送`@A=-1000`，巡航、菜单、停车和错误状态发送
`@A=0`。`Ramp Tilt Test`同样发送`@A=1000`并在3秒内把共同速度目标从0升到约30。

所有`@BALL=`命令都是一次性请求，不是保活帧。它们只影响H7本地任务的可选启停
入口；H7本地控制任务的运行不依赖M0持续发送命令。

Task1只被动显示外部M0姿态，不向H7发起yaw测量。Task2/6/7循迹不向H7发送
转向命令。Gmr没有任何H7到M0的UART2消费者：H7姿态不走这条链路，任务命令和
`@BALL=RUN`/`@BALL=STOP`也不再解析。H7侧IMU不参与M0底盘航向或转向控制。

## 构建

```powershell
.\tools\build_ccs.ps1 -Profile Gmr -Clean
```

默认等价于天猛星、蓝牙关闭、JY61关闭、UART0日志关闭。构建不会自动烧录。
