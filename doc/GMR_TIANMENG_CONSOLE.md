# 天猛星 Gmr 赛题控制台

当前Gmr是天猛星单一发布目标，提供姿态、灰度循迹、编码器、可调闭环、方向检查、
灰度差速和连续巡线七个本地任务。旧地猛星、双车蓝牙和完整串口PID实现不进入
当前Gmr链接结果。

## 当前外设

| 外设 | 资源 | 当前用途 |
| --- | --- | --- |
| 左右编码电机 | TIMA0 PWM + 4路编码GPIO | Task2/4~7驱动，Task1/3强制停车 |
| 七路数字灰度 | PA15/16/17/24/25/26/27 | Task2/6/7七路加权差速，高电平表示压线 |
| 五个按键 | PB0/1/11/10/21 | K1/K2/K3/K4/K5，低电平按下 |
| H7通信 | UART2，PB15 TX / PB16 RX | LCD文本输出、任务启动和停止 |
| 外部M0姿态 | UART3，PB2 TX / PB3 RX | 100 Hz连续yaw和yaw角速度 |
| 本地OLED | I2C0，PA0 SDA / PA1 SCL | 显示姿态数据和链路统计 |

UART0、UART1、蓝牙、云台STEP和IMU660RX在当前Gmr默认构建中不初始化。

## 当前任务

`Attitude`任务是被动监视页，显示：

- 连续yaw，单位0.01度转换为两位小数；
- yaw角速度，单位0.01度每秒转换为两位小数；
- M0发送序号、有效帧数和坏帧数。

任务进入和退出都会调用`EncoderMotor_Stop()`，不会根据姿态数据驱动电机。

`Task2 A-A`进入时清零左右累计编码器，随后持续使用七路灰度加权差速循迹，
不请求H7按陀螺仪执行转向。基础速度从12 count/20ms起步，在2秒内线性升到
35 count/20ms。当右轮count严格大于45000并且左轮count严格大于36000时，
立即停车并进入`Finished`；两个阈值必须同时满足。也可提前按K3或发送
`@STOP`停止任务。Task2启动时同时开始计时，离开运行态时冻结；运行页和自动完成
页显示`MM:SS`；H7使用32像素原生字体，本地OLED使用24像素原生字体。其他没有
明确自动结束条件的测试任务不计时。

`Encoder`任务进入时会清零左右累计编码器count，随后持续显示左右带符号累计
count，供手推轮子检查正交编码器方向和计数。任务全程保持电机停车。

`Drive Adjustable`任务使用编码器速度闭环。主菜单按K2后先设置左轮，再设置右轮；
K1加1、K4减1、K2进入下一页或启动、K3返回。范围为0~100 count/20ms，默认
左15、右27。OLED运行页显示左右目标、实际反馈和raw PWM；任务持续运行到按K3
或收到`@STOP`。首次运行必须架空车轮并准备物理断电。

`Direction +20`用于核对正方向。进入页面先停车；K1在`PWM +20%`与闭环
`+20 count/20ms`之间切换并停车，K2启动或停止当前模式。20%对应`+240 raw PWM`。
OLED显示左右Actual与raw PWM，正PWM时两侧实际编码都应为正。

`Gray Differential`每20 ms读取S1~S7数字灰度，按`13,7,3,0,-3,-7,-13`
求激活通道平均位置。基础目标为左右35 count/20ms，位置误差乘2后形成差速并限制
在0~42；线在左侧时左轮减速、右轮加速，线在右侧时相反。丢线后沿用最后一次
有效灰度对应的左右目标2000 ms，超时仍未重新压线才停车。
OLED显示七位灰度mask以及左右Target、Actual和raw PWM。

`Line Follow`与`Task2 A-A`使用同一套连续七路灰度控制：左右基础目标均为35
count/20ms，灰度位置误差直接形成左右轮差速。它不包含编码器分段、H7陀螺仪
转向、旧直角检测、强转或出弯状态；丢线仍保持最后目标2000 ms后停车。

本地按键均为短按：K1下一项、K4上一项、K2确认/启动、K3退出/停止；K5事件已接入
驱动，当前菜单暂未分配动作。

## H7协议

链路固定为115200、8-N-1，MCU TX接H7 RX，MCU RX接H7 TX，双方共地。

M0到H7沿用文本LCD协议：

```text
@CLEAR\n
@L0=GMR Tianmeng\n
@L1=> Attitude\n
@T=00:12\n
```

`@T=MM:SS`是Task2专用计时页面命令；H7收到后使用32像素原生ASCII字库显示，
不再把数字编码成`#`字符画。后续收到`@CLEAR`或任意`@L0`至`@L9`命令时，H7
退出计时页面并恢复普通文本显示。

H7到M0当前支持：

```text
@START=1\n
@START=2\n
@START=3\n
@START=4\n
@START=5\n
@START=6\n
@START=7\n
@STOP\n
```

`@START=1`到`@START=7`依次对应上述七个菜单任务。

Task1只被动显示外部M0姿态，不向H7发起yaw测量。Task2/6/7循迹不向H7发送
转向命令，也不接收H7转向完成信号。H7侧IMU不再参与M0底盘航向或转向控制。
解析在UART2 ISR中只生成命令，状态事件由5 ms Comm任务投递给Mission任务。

## 构建

```powershell
.\tools\build_ccs.ps1 -Profile Gmr -Clean
```

默认等价于天猛星、蓝牙关闭、JY61关闭、UART0日志关闭。构建不会自动烧录。
