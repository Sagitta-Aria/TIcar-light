源码改动与上板顺序

首次上板顺序

  1. 断开电机动力电源，只保留逻辑电源。
  2. 确认两块板共地，核对 3.3V 与 VBUS_5V，禁止互相短接。
  3. 先验证 OLED、K1-K5、Type-C 日志、K230 UART 和 JQ8400 UART1。
  4. 确保 Flash CS 与 IMU CS 均为高电平，再验证 LSM6DSRTR 的 WHO_AM_I=0x6B 和 INT1。
  5. 继电器先不接负载，只确认 PB27 上电保持关闭且控制极性正确。
  6. 确认 PB23/PB25 上电低电平时两只外接 LED 熄灭，再空载测量 PA14 的 PWM 频率和占空比。
  7. 架空车轮，使用 Task5 低 PWM 分别检查方向与编码器符号。
  8. 重新标定左右轮 start、FF、Kp/Ki；旧参数不能直接视为实车最终值。
  9. 最后接地验证 Task1，再逐项验证 Task2-Task4。

电源与特殊网络

电源不计入 GPIO 迁移统计，但接错会直接损坏板卡或外设。

地猛星 +5V

迁移到天猛星 VBUS_5V 排针，例如 U21-24/U21-40 或 U22-24/U22-40。它是 USB 5V 网络，不是 3.3V GPIO 电源。

地猛星 3V3

迁移到天猛星 EXT_3V3，例如 U21-22/U21-38 或 U22-22/U22-38。

GND / AGND

数字外设使用 GND；模拟参考回路优先使用 AGND。天猛星板内通过 R42=0Ω单点连接两者。

PA21 / PA23

天猛星把它们标为 VREF-/VREF+ 网络。推荐方案把两路电机方向迁到 PA29/PA30，避免后续启用外部参考电压时产生冲突。

SPI1 / LSM6DSRTR

IMU 与板载 Flash 共享 PB7/POCI、PB8/PICO、PB9/SCK；Flash 保持 PB6/CS0，IMU 单独使用 PB14/CS。任一器件通信时，另一个 CS 必须保持高电平。

PB27 / 继电器

PB27 只接继电器模块控制输入或外部三极管/MOSFET 驱动级，上电默认关闭。禁止 GPIO 直接驱动继电器线圈，线圈侧需要续流保护。

PA14 / PWM 与 PB23/PB25 / LED

PA14 使用 TIMG12 CCP0 输出扩展 PWM。PB23/PB25 分别驱动两只外接 LED，按 GPIO→限流电阻→LED→GND 接线，高电平点亮；每路必须串联 330Ω～1kΩ 电阻。

逐飞 IMU660RB 接线

模块核心为 LSM6DSR，下面按逐飞模块背面丝印记录 SPI 接法；推荐使用 3.3V 供电。
