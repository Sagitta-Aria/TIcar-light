# C 语言和单片机小抄

这份笔记专门给你补 `gray.c` 里出现的常用 C 语法和单片机概念。

## 1. `typedef struct`

```c
typedef struct {
    ADC12_Regs *adc;
    DL_ADC12_MEM_IDX mem;
} GrayAdcSlot;
```

含义：

- `struct`：定义一个结构体类型
- `typedef`：再给它起一个好记的别名

好处是后面能直接写：

```c
GrayAdcSlot slot;
```

而不是：

```c
struct GrayAdcSlot slot;
```

## 2. 指针 `*`

```c
ADC12_Regs *adc;
```

这里的 `*` 是“指针声明”。

你可以先把它理解成：

```text
变量里放的不是实体，而是地址
```

单片机里特别常见，因为很多外设都通过“寄存器地址”操作。

## 3. `->` 和 `*`

如果有一个指针：

```c
ADC12_Regs *adc;
```

那么：

- `adc` 是地址
- `*adc` 是这个地址指向的对象
- `adc->xxx` 是访问结构体里的成员

这类写法是单片机里读寄存器风格的基础。

## 4. `static`

```c
static uint16_t g_grayRaw[GRAY_SENSOR_COUNT];
```

`static` 放在文件级变量前面，意思是：

- 只能在当前 `.c` 文件里用
- 外部文件看不到

这能避免变量被别的模块乱改。

## 5. `const`

```c
static const int16_t g_grayWeight[GRAY_SENSOR_COUNT] = {
    -3, -2, -1, 0, 1, 2, 3
};
```

`const` 表示这个数组内容不应该被修改。

它适合放：

- 权重
- 配置表
- 只读映射

## 6. `uint8_t`、`uint16_t`、`uint32_t`

这是固定宽度整数类型：

- `uint8_t`：8 位无符号整数
- `uint16_t`：16 位无符号整数
- `uint32_t`：32 位无符号整数

在单片机里比 `int` 更稳，因为你能明确知道变量占多少位。

## 7. `0U`、`1U`

```c
0U
1U
```

`U` 表示无符号常量。

常见用途：

- 循环计数
- 状态标志
- 和 `uint32_t` 搭配

## 8. 三目运算符 `?:`

```c
return (raw >= threshold) ? 1U : 0U;
```

它等价于：

```c
if (raw >= threshold) {
    return 1U;
} else {
    return 0U;
}
```

## 9. ADC 在单片机里是什么

ADC = 模数转换器。

作用是把传感器输出的模拟电压变成数字值。

在这块板子里：

- 灰度传感器输出的是模拟电压
- ADC 把它变成 0 到 4095 的数字
- 程序再用阈值判断黑线还是白底

## 10. `MEM` 槽是什么

ADC 的结果通常不会“直接蹦出来”，而是先放进一个结果槽。

你可以把 `MEM` 槽理解成：

```text
ADC 的收件箱
```

每路传感器对应一个槽位，程序再去读这个槽位里的结果。

## 11. 这块板子的灰度输入不是一根线

你看到的是 7 路灰度，但底层是：

- 两个 ADC 外设
- 多个 MEM 槽
- 一张映射表 `g_grayMap`

这就是“硬件复杂，软件整理”的典型例子。

## 12. 单片机里最常见的思维

以后你看代码可以先问自己这 4 个问题：

1. 数据从哪来
2. 数据放哪
3. 谁来更新
4. 谁来使用

套到灰度模块里就是：

- 从 ADC 来
- 放进 `g_grayRaw` 和 `g_grayDigital`
- `Gray_Update()` 负责更新
- 循迹逻辑负责使用

## 13. 一句话记忆版

```text
指针负责找地址，struct 负责装多个字段，ADC 负责把电压变数字，0U 负责告诉编译器这是无符号 0
```
